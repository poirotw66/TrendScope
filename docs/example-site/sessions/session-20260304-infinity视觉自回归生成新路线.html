2. 技術要點和實現細節

Infinity 的技術核心在於其對視覺自回歸模型進行的根本性改造，尤其是在離散化策略和誤差處理上的創新。

2.1 視覺自回歸 (VAR) 的基礎與挑戰

  • 序列建模： 傳統自回歸模型通過預測序列中的下一個令牌（token）來生成內容。在視覺領域，這意味著將圖像壓縮並離散化為視覺序列。
  • 「下一尺度/下一解析度」預測： Infinity 採用一種從粗到細的生成策略，類似於人類感知或繪畫過程，從整體框架開始，逐步填充細節。這種方式被認為比傳統的光柵掃描（raster scan）順序更自然且高效。
  • 挑戰： 傳統 VAR 在高解析度圖像生成方面性能不佳；尚未展現 LLM 式的縮放法則；預測速度慢；光柵掃描順序導致全局信息丟失；教師強制訓練導致累積誤差。

2.2 Infinity 的核心技術突破

Infinity 旨在解決上述挑戰，提出了一個全新的「位元級建模框架」：

  1. 位元級令牌器 (Bitwise Tokenizer) 與二進制球面量化 (BSQ)：

    • 技術細節： 傳統方法（如 VQVAE）將圖像編碼為離散的索引，存在顯著的量化誤差，導致重建圖像細節丟失。Infinity 引入位元級令牌器，採用二進制球面量化 (BSQ)，將圖像特徵直接量化為一系列的 +1 或 -1 位元。
    • 無限詞彙分類器： 傳統方法預測一個碼本中的有限索引（例如 2^16 個），而位元級建模直接預測構成視覺信息的每個位元。這實際上創造了一個「無限詞彙」的空間（例如，預測 d 個位元而非 2^d 個索引），從而大幅減少了量化誤差，保留了更多高頻紋理細節。
    • 性能提升： 實驗數據顯示，隨著詞彙量 Vd 從 2^16 擴展到 2^64，位元級令牌器在 ImageNet-rFID 上的表現顯著優於 SD 的連續 VAE (例如 Vd=2^64 時，IN-256 rFID 為 0.33，優於 SD VAE 的 0.87)。

  2. 位元級自校正 (Bitwise Self-Correction)：

    • 問題： 自回歸模型在教師強制 (teacher forcing) 訓練下，模型在測試時會遇到累積誤差，因為其預測的基礎是自己的錯誤輸出，而非完美的真實數據。
    • 解決方案： Infinity 引入位元級自校正機制。在訓練過程中，它會隨機翻轉部分位元以模擬實際預測中的誤差。接著，模型會重新量化殘差特徵 (residual features) 以自動糾正這些「模擬」的錯誤。
    • 效果： 該機制有效緩解了訓練-測試不一致問題，顯著提升了生成模型的穩健性。數據顯示，經過位元級自校正後，FID 從基準線的 ~9.7 大幅降低至 3.48，ImageReward 從 0.52 顯著提升至 0.76，生成圖像質量獲得實質性改善。

  3. GPT 風格的變換器 (AutoRegressive in Scale Space Transformers)：

    • Infinity 在多尺度空間中部署了類似 GPT 的變換器架構，以實現從粗到細的自回歸生成。這種架構利用了變換器在序列建模方面的強大能力。
    • 縮放法則驗證： 簡報展示了 Infinity 在不同模型大小 (125M 到 4.7B) 下，驗證損失隨訓練迭代次數和 FLOPS 呈現下降趨勢，證明了其與 LLM 相似的 Scaling Law 特性，預示著未來性能可通過擴大模型規模和數據集進一步提升。

  4. 直接偏好優化 (DPO)：

    • 雖然簡報未詳細闡述 DPO 的具體實施細節，但其對比圖像暗示了 DPO 被用於對模型生成的內容進行進一步微調，以優化圖像質量、風格或更精確地符合人類偏好。

2.3 性能數據與效率

  • SOTA 質量： Infinity (2B) 在 ImageNet 512x512 條件生成任務上，FID 達到 2.63，超越 DiT-XL/2 的 3.04。在 GenEval 和 DPG 等基準測試中，Infinity (2B) 的綜合分數也超越了 SDXL、PixArt-Sigma 和 SD3 等領先擴散模型。
