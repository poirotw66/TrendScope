1. 會議概述和核心內容

本次由常高偉先生在 2025 年 AICon Beijing 發表的主題演講，旨在深入探討智能體（Agent）互聯網的未來圖景及其底層支撐協議。演講的核心要旨是：隨著人工智能技術的飛速發展，智能體將逐漸取代現有的軟體形態，並成為人與數字世界交互的主流方式。然而，要實現數十億智能體的互聯互通與高效協作，當前以 API 或瀏覽器為基礎的互聯網架構已顯不足。因此，演講重點介紹並對比了三種關鍵的智能體協議：模型上下文協議 (MCP)、智能體對智能體協議 (A2A) 和智能體網絡協議 (ANP)，旨在分析它們的特性、優劣勢及適用場景，並擘劃智能體互聯網的未來架構。

核心內容涵蓋了智能體互聯網的趨勢、協議的重要性、三種協議的技術細節與差異、智能體互聯網的未來展望，以及 ANP 開源社區的發展現狀，為業界描繪了一個由智能體驅動的下一代互聯網願景。

2. 技術要點和實現細節

本次研討會詳細闡述了智能體協議的必要性及其在未來互聯網中的作用，並深入分析了三種主流協議的技術實現。

2.1 協議的重要性與挑戰 協議被定義為系統間通信的規則，包含數據格式、交換流程和角色約定。對於 AI 或智能體而言，協議能提供 AI 原生的連接方式，實現標準化、高效、低成本的交互。相較於現有的 API、計算機使用或瀏覽器使用方式，協議能有效解決數據孤島問題，並專為 AI 打造，最終目標是建立行業共識以實現標準化。

2.2 MCP (Model Context Protocol) * 定位： MCP 是一個開放協議，專為大型語言模型 (LLM) 應用與外部數據源和工具之間的無縫集成而設計。它被形象地比喻為「模型的 USB-C」。 * 核心概念： 包含 Root (安全文件訪問)、Sampling (利用客戶端 AI 能力)、Prompt (伺服器公開提示模板)、Resource (伺服器公開資源) 和 Tools (伺服器公開可調用工具)。 * 實現細節： 採用典型的 C/S (Client-Server) 架構，客戶端主動連接伺服器。傳輸層基於 HTTP (也支援 stdio)。身份認證基於 OAuth2.1，屬於中心化方案，要求在對方系統註冊帳號。信息組織採用 JSON-RPC。 * 適用場景： 主要用於模型連接外部工具與資源，例如將 LLM 整合到 IDE、聊天界面或自定義 AI 工作流中。目前已成為模型連接工具與資源的事實標準。

2.3 A2A (Agent to Agent) * 定位： 專為企業內部智能體協作場景設計，基於任務的交互模式。 * 核心概念： 強調 Task (任務)、Artifact (產物)、Message (消息) 和 Part (部分)，並支援 Push Notifications。 * 實現細節： 採用 P2P (Peer-To-Peer) 架構，支援智能體之間複雜的協作。傳輸層基於 HTTP。身份認證方案較為缺失，透過帶外 (out-of-band) 方式獲取驗證材料 (類似 OpenAPI)，協議本身不提供內建的身份方案。信息組織採用 JSON-RPC。 * 適用場景： 偏向企業內部的智能體任務協作，解決內部智能體間的複雜交互問題。

2.4 ANP (Agent Network Protocol) * 定位： ANP 的願景是成為智能體互聯網時代的 HTTP，旨在定義 Agent 之間的連接方式，為數十億智能體構建一個開放、安全、高效的協作網絡。 * 核心特性： 全球首個面向智能體設計的通信協議，旨在實現任意兩個智能體的互聯互通，構建便於 AI 訪問的數據網絡，並讓智能體能夠自主組織、自主協商。 * 分層架構： * 應用協議層： 處理智能體描述 (Agent Description)、智能體發現 (Agent Discovery) 和智能體協議管理器 (Agent Protocol Manager)。 * 元協議層： 處理協議協商 (Protocol Negotiation)、協議除錯 (Protocol Debugging) 和協議測試 (Protocol Testing)，實現智能體的自組織與自協商。 * 身份與加密通信層： 基於 W3C DID (Decentralized Identifiers) 處理智能體身份，並實現端到端加密通信 (E2E)。 * 實現細節： * 身份方案： 採用 W3C DID，提供去中心化的、具有良好互操作性的分布式身份認證，智能體無需在對方系統註冊即可交互，類似電子郵件的機制。 * 智能體描述： 採用 JSON-LD 和 schema.org 等語義網相關技術，使智能體能夠對外公開其基本信息、能力和接口，形成便於 AI 讀取和理解的數據網絡。 * 智能體發現： 基於 DNS，採用類似 Web 站點的發現技術 (如 /.well-known/agent-descriptions URI 路徑的主動發現和向搜索服務註冊的被動發現)，使搜索引擎能夠發現全網智能體。 * 架構： 典型的 P2P (Peer-To-Peer) 架構，任意智能體都可以發起與對方的連接。傳輸層基於 HTTP。信息組織基於 Linked-Data (語義網)。 * 適用場景： 面向廣泛的智能體互聯網，旨在解決智能體跨平台、跨組織的連接、通信、身份、描述和發現等核心問題。

3. 商業價值和應用場景

智能體協議的發展，預示著一個龐大而富有變革性的商業藍圖。

3.1 驅動「Agentic Web」的轉型升級 * 取代現有軟體與服務： 智能體將取代人們訪問互聯網的行為和企業的軟體服務，這將重塑軟體產業的交付模式和用戶交互界面。 * 釋放 AI 潛力： 透過協議打破數據孤島，AI 能夠獲取完整的上下文信息並調用全部工具能力，從而極大提升 AI 的決策能力和執行效率。 * 創建 AI 原生連接： 協議提供 AI 原生的連接方式，使智能體能直接處理底層數據，這是目前 API 等方式難以比擬的效率提升。

3.2 三種協議的商業價值與定位 * MCP 的商業價值： 作為模型與工具、資源連接的事實標準，MCP 有助於加速 LLM 在各種應用中的集成與落地。例如，AI 驅動的 IDE、增強型聊天界面和自定義 AI 工作流，都能透過 MCP 高效連接數據庫、雲服務、GitHub 等外部資源，大幅提升 AI 應用的開發效率和功能豐富性。 * A2A 的商業價值： 主要體現在 B 端企業內部的智能協作。透過 A2A，企業內部不同職能的智能體可以高效協作完成複雜任務，優化業務流程，降低運營成本。其合作夥伴生態集中於 AI 平台、SaaS、IT 服務和數據基礎設施等領域，顯示其在企業級市場的深耕。 * ANP 的商業價值： 旨在構建一個開放的、全球性的智能體互聯網絡。 * 去中心化生態： W3C DID 的應用使得智能體可以跨平台、跨組織地進行身份認證與交互，無需重複註冊帳號，這將極大降低智能體協作的摩擦成本，催生前所未有的智能體服務市場。 * AI 原生的數據網絡： 基於語義網和 JSON-LD 的描述，使得數據對 AI 而言是「自描述」和「可理解」的，從而能更高效地被發現、利用，大幅提升智能體服務的準確性和智能化程度。 * 廣泛的應用場景： * 電商交互： 個人智能體可與搜索、信用、支付、仲裁、服務（如酒店）智能體協作，實現從搜索、預訂、支付到售後的全流程智能體驗，顛覆傳統電商模式。 * 即時消息： 透過 DID 交換，智能體可實現安全、私密的點對點消息收發，並由群組智能體管理群聊，提升通信效率和智能化。 * 內容分發： AI 創作內容、智能體通知好友粉絲、搜索引擎智能體索引、推薦智能體分發，實現內容生產、分發、消費全鏈路的智能化。 * 重塑互聯網格局： ANP 的目標是讓互聯網從平台為中心回歸到連接為核心，這將挑戰現有中心化平台的商業模式，為更多去中心化、開放式的創新服務提供基礎。

4. 創新亮點和技術突破

本次會議展示了智能體協議領域的一系列創新亮點與技術突破，尤其以 ANP 的設計理念最具開創性。

4.1 AI 原生設計思維的創新 所有三種協議都體現了為 AI 或智能體量身定制的設計思路，而非僅僅將現有 Web 技術應用於 AI。這體現在對數據格式、交互流程和身份認證的重新思考。特別是摒棄了傳統以人為中心的 UI 界面，轉而設計「UI-less」、便於 AI 直接訪問和理解的數據網絡，這是核心的思維轉變。

4.2 ANP 在去中心化與互操作性方面的突破 * W3C DID 去中心化身份： ANP 採用 W3C DID 方案是其最核心的技術突破。它解決了數十億智能體在開放互聯網中進行跨平台、跨組織通信時的身份認證難題。傳統中心化 OAuth 方案需要重複註冊帳號，成本極高且效率低下。DID 賦予每個智能體一個獨特的、可互操作的身份 ID，實現了真正的去中心化認證，極大降低了智能體協作的門檻，提升了安全性和隱私性。 * JSON-LD 與語義網（Linked-Data）的應用： ANP 透過 JSON-LD 和 schema.org 實現智能體的「自描述」能力，使得智能體不僅能公開其功能，還能以 AI 可理解的方式描述其語義信息。這打破了傳統 API 僅提供接口但不提供語義上下文的局限，讓 AI 能夠更智能地發現、理解和調用其他智能體，構建真正的 AI 原生數據網絡。 * 基於 DNS 的智能體發現機制： 借鑒 Web 站點的成熟發現機制，ANP 透過 DNS 實現了智能體的全球化、標準化發現。這對於建立一個龐大且不斷增長的智能體生態系統至關重要，如同搜索引擎發現網頁一樣，智能體可以發現其他智能體及其能力。 * P2P 黑盒解耦架構： ANP 採用的 P2P 架構和「黑盒」設計原則，使得智能體之間的交互更為鬆散耦合。它更關注智能體的「信息」和「接口」，而非複雜的內部「任務」流程。這種設計有利於構建一個高度可擴展、富有彈性且不高度依賴單一中心節點的智能體互聯網。

4.3 A2A 在企業協作模型上的創新 A2A 雖然主要針對企業內部，但其基於「任務的交互模式」設計，對於解決智能體之間複雜的流程協作問題提供了一種創新思路。其對「任務與狀態管理」、「用戶體驗協商」和「能力發現」的強調，有助於企業內部智能體系統的高效集成。

4.4 MCP 作為模型與工具連接的事實標準 MCP 在 LLM 與外部工具及資源連接方面，透過標準化的核心概念（Root, Sampling, Prompt, Resource, Tools）提供了一套開箱即用的解決方案，這填補了模型與現實世界交互的鴻溝，加速了 AI 大模型應用的普及，其「模型的 USB-C」的比喻精準地捕捉了其作為基礎連接器的價值。

5.2 智能體互聯互通的必然性 當前互聯網存在的數據孤島，極大地限制了 AI 的潛力。未來，AI 必須能夠獲取完整的上下文信息，調用全部工具能力。因此，Agent 之間的連接性將佔據更高比重，互聯互通是智能體生態發展的必然路徑。

5.3 AI 原生數據網絡的崛起 未來的互聯網將是一個「AI 原生」的數據網絡，其特點包括： * UI-less 設計： 專為 AI 訪問而非人設計。 * 半結構化數據： 以結構化格式為主，便於 AI 處理和理解。 * 自描述能力： 基於語義網技術，數據和智能體本身具備豐富的語義描述信息，使得 AI 無需預先訓練即可理解其功能和內容。 這將是一個從根本上為 AI 優化的信息生態系統，極大地提升 AI 的效率和智慧。

5.4 消費互聯網與產業互聯網的深度融合 會議預測，以人為中心的消費互聯網將與以機器為中心的產業互聯網深度融合。透過智能體協議的「連接工具」，這兩個網絡將無縫連接，形成一個更廣泛、人與智能體共同協作的網絡，催生出更多跨領域的創新服務。

5.5 新型交互模式的普及 未來的電商、即時消息和內容分發等核心互聯網服務，都將由多個智能體協同完成。例如，電商交易中個人智能體將與搜索、信用、酒店、支付、仲裁等智能體無縫協作，提供極致流暢和智能化的體驗。這種去中心化、多智能體協作的模式將根本性地改變用戶體驗和服務供給方式。
