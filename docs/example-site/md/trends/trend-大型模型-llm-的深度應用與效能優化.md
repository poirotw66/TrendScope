## 趨勢描述

大型語言模型（LLM）已成為當前 AI 發展的核心驅動力，其應用正從通用領域向特定場景深化。研討會內容顯示，LLM 廣泛應用於智能硬體（如詞典筆）的端側部署、知識庫問答體系革新（RAG）、企業級風險控制、數據治理及垂直產業應用。為確保這些應用的可行性與擴展性，大模型訓練的穩定性、推理效能優化（如萬卡規模訓練、高效開源服務框架 SGLang、數據湖查詢加速）以及數據調優的高效構建與進化方法，成為關鍵的技術挑戰與研究方向。
