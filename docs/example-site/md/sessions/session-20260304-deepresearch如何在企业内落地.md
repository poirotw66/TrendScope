## DeepResearch 在企業內落地：綜合分析報告

### 報告標題：DeepResearch 如何在企業內落地
### 研討會：202506 AICon Beijing
### 演講人：覃睿 (BISHENG / 聯合創始人)

---

### 1. 會議概述和核心內容

本次 AiCon Beijing 主題演講深入探討了大型模型 (LLM) 在企業應用落地中面臨的普遍挑戰，並提出 **DeepResearch** 作為破局的「新變量」，以及畢昇靈思 (BISHENG·Linsight) 所提供的具體解決方案。演講開宗明義地指出，儘管大模型展現出巨大潛力，但在企業環境中，從概念驗證到實際價值創造的道路卻充滿坎坷，常出現「上線 Demo 一週，優化效果半年」的困境。

核心內容聚焦於 DeepResearch 這一新型智能體能力，它旨在透過多步驟、跨領域的自主研究，連接技術與業務，顯著降低大模型應用的開發門檻和實施成本。畢昇靈思的解法，則圍繞著建立標準操作流程 (SOP) 體系、融入人機協作 (HITL)、強化上下文管理、擴展實用工具生態，並通過不斷的反饋迭代機制，解決企業級應用在複雜性、精確性、可控性及成本等方面的痛點，最終推動企業實現 AI 的規模化賦能。整個演講傳達了「理性樂觀，做好持久戰準備」的務實態度。

### 2. 技術要點和實現細節

#### 2.1 DeepResearch 技術概念與運作機制

*   **核心定義：** DeepResearch 被定義為一種能夠針對複雜任務在互聯網上進行多步驟研究的新智能能力。它超越了單純的知識問答或簡單指令執行，強調 AI 智能體自主規劃、執行、反思和迭代的能力。
*   **Agentic Capability (智能體能力)：** 這是 DeepResearch 的基礎。它涉及將複雜任務拆解為多個子任務，由 AI 智能體（Agent）自主判斷執行路徑、調用工具、獲取信息、分析結果，並根據反饋調整策略，直至達成最終目標。
*   **多智能體結構：** 簡報中對多個開源類 DeepResearch 項目（如 OpenManus, Deerflow, AutoGPT, Xagent）的比較顯示，這類系統普遍採用任務拆解、多 Agent 協同、上下文管理和基於 LLM+工具執行的模式。每個 Agent 可能負責不同的職責（如規劃者、執行者、報告者），通過溝通協議協同工作。
*   **工具調用 (Tool Calling)：** 大模型通過調用外部工具（如瀏覽器、文件系統、數據分析工具、業務系統接口）來擴展其感知和行動能力，彌補其知識庫的實時性與操作的局限性。演講特別強調了 MCP (Multi-Agent Communication Protocol) 在未來工具生態中的重要性。
*   **上下文管理：** 處理企業級複雜任務（如幾十萬字的報告撰寫）對模型的上下文長度提出極高要求。DeepResearch 不僅要求模型能處理長上下文，更需要一套精妙的上下文管理機制，以確保在多步驟執行中信息的連貫性、避免遺忘和混淆，並支持獨立任務的並行處理。

#### 2.2 BISHENG·Linsight 的技術實踐

畢昇靈思 (BISHENG·Linsight) 在上述通用技術基礎上，提出了多項針對企業級應用的創新：

*   **SOP 體系作為核心中介：** Linsight 將標準操作流程 (SOP) 視為解決任務複雜性、保證精確性的關鍵。SOP 不僅承載了領域知識和用戶偏好，更成為 AI Agent 執行任務的「指導手冊」，並負責收集反饋、積累經驗，形成一個自我優化閉環。這暗示 Linsight 更傾向於通過優化 SOP 而非直接對模型進行大規模領域微調，以實現通用模型在特定業務場景的高效應用。
*   **人機協作 (Human-in-the-Loop, HITL)：** Linsight 深刻理解企業對精確性和可控性的高要求，將 HITL 納入其核心設計。在關鍵環節，AI Agent 可以主動請求人類用戶的介入、確認或指導，例如在任務拆解、信息篩選或結果審核時。這不僅提升了結果的可靠性，也使業務人員能深度參與到 AI 應用的構建和優化中。
*   **任務管理框架與並行處理：** 針對上下文長度和執行鏈路過長的問題，Linsight 設計了高效的任務管理框架，支持將複雜任務拆解為獨立的子任務並行處理。這不僅提升了執行效率，也減少了單一模型處理超長指令鏈路時可能出現的指令遵循能力下滑問題。
*   **企業級工具與 MCP 生態：** Linsight 致力於提供實用的企業級工具，例如將 Markdown 生成內容轉換為 Office 文件、圖表繪製、用戶文檔與知識庫文檔的搜索與分析等。同時，積極建立企業內部的 MCP 生態，促進多智能體之間以及智能體與企業系統之間的無縫協同。
*   **自動化基準測試構建：** 針對企業級任務缺乏標準答案、難以評測的挑戰，Linsight 提出構建類似「新 ImageNet」的基準測試。這需要業務專家深度參與，依賴實際業務沉澱，並通過多維度評價標準（如完整性、準確性、一致性、長度等）讓大型模型進行自動化打分，推動持續改進。

### 3. 商業價值和應用場景

#### 3.1 解決企業大模型落地的核心困境

演講明確指出企業大模型落地的四大主要原因，而 DeepResearch 正是針對這些痛點提供了商業價值：

*   **認知與方法論 (80%)：** 企業往往對大模型抱有不切實際的期望，缺乏有效的迭代演化方法論。DeepResearch 透過其Agentic能力和BISHENG·Linsight的SOP體系，提供了一種更為務實且可控的開發與優化框架，將業務知識轉化為可執行SOP，降低了方法論的門檻。
*   **優質人才 (50%)：** 大模型項目高度依賴兼具模型能力與業務認知的複合型人才。DeepResearch 的「自然語言本身就是編程語言」理念和「技術平權」願景，旨在讓更多業務人員無需深厚技術背景即可參與到 AI 應用的構建中，緩解人才稀缺問題。
*   **企業級可控 (10%)：** 企業對可靠性、安全性、成本控制要求嚴格。BISHENG·Linsight 透過 HITL、企業級特性以及清晰的SOP管理，提升了AI應用的可控性與可信賴度。
*   **場景爆發與全員參與 (1%)：** DeepResearch 的最大優勢在於處理零散、泛在的長尾場景，其目標是提升所有員工的效率並激發全員自發使用。它將大模型從少數高精尖的項目轉化為普惠的生產力工具。

#### 3.2 廣泛的應用場景與商業效益

簡報中列舉了大量「低垂果實」和更複雜的應用場景，展現了 DeepResearch 的巨大商業潛力：

*   **通用場景：** 智能問答（知識庫、客服）、內容審核（合同、文件）、報告生成（日報、盡調報告）、知識管理（摘要、標籤、要素提取）、數據分析（查詢、可視化）、文件生成、會議管理、風險預警等。這些應用能顯著降低人力成本、提升工作效率、確保內容一致性和準確性。
*   **泛金融行業：** 信貸盡調與審批、政策文件對比、投研報告撰寫、貸後管理、反洗錢評級、產品培訓材料生成等。DeepResearch 可加速複雜的金融流程，提高合規性，支持精準決策。
*   **其他行業：** 航空/機場客服、物業運營、街道社區管理、大宗貿易商情分析、電信客服自動化、政務報告、軍工報告、大健康信息處理、能源合同審核、教育教案生成、公安案卷輔助、建築工程報告、芯片企業客戶支持等。這些場景通常涉及大量非結構化數據處理、跨部門協作和複雜決策，DeepResearch 能在這些領域提供強大的自動化和智能輔助。

通過 Linsight 在「投標文件撰寫」、「招股書閱讀報告」和「合同審核」等案例中的實踐，我們看到 DeepResearch 能夠從零散的輸入中提取關鍵信息，執行複雜的邏輯推理，並生成結構化、內容豐富的輸出。儘管尚需人工微調，但已極大地提升了初始生成效率和內容完整性，為企業節約了大量人工時間和成本。其核心商業價值在於 **降低構建門檻、提高效率、賦能業務用戶，並解決傳統 IT 難以覆蓋的長尾、輕分析需求。**

### 4. 創新亮點和技術突破

#### 4.1 從 Workflow 到 DeepResearch 的範式轉變

這是本次演講最核心的創新點之一。傳統工作流 (Workflow) 依賴預設的固定流程和邏輯分支，適用於標準化程度高的任務。而 DeepResearch 代表了從「固定流程」到「動態智能體」的範式轉變。它賦予 AI 系統自主規劃、動態調整策略、基於環境反饋進行多步驟決策的能力，極大地提升了自動化處理複雜、非標準化任務的靈活性和應變性。這標誌著「輕應用」時代的到來，讓應用構建更加敏捷和以自然語言為中心。

#### 4.2 SOP 體系與人機協作 (HITL) 的創新融合

Linsight 提出的 SOP 體系，是將企業沉澱的領域知識、業務邏輯和用戶偏好，以標準化操作流程的形式，內化為 AI Agent 的行為準則。這不僅解決了領域知識的傳承問題，更為 AI 的執行提供了清晰的指導。結合 HITL，SOP 不再是靜態的，而是在人機協作的反饋閉環中動態優化和演進。這種結合創新性地平衡了 AI 的自主性與企業對精確性、可控性的需求，是實現企業級 DeepResearch 實用性的關鍵突破。

#### 4.3 多智能體協同與 MCP 協議

DeepResearch 的本質是協同智能。多 Agent 結構將複雜任務拆解給多個專業 Agent 處理，並通過 MCP 協議實現高效溝通和任務協調。這種架構使得系統能夠處理更複雜、多維度的企業任務，並允許各 Agent 專精於特定工具或知識領域，提升整體效率和質量。這預示著未來企業 AI 系統將是一個由多個智能體組成的生態系統。

#### 4.4 針對性基準測試的構建理念

在「投标文件撰寫」等無標準答案、多維度評估的複雜企業場景中，傳統基準測試已無法勝任。Linsight 提出的「新 ImageNet」概念，旨在建立針對企業實際應用場景的自動化評測體系。通過引入業務專家沉澱數據實例，並利用大型模型進行多維度自動化打分，這是一種在主觀性和複雜性高的領域實現客觀評測的創新方法，對於加速 DeepResearch 在企業場景的迭代和優化具有里程碑意義。

#### 4.5 技術「平權」與業務賦能

DeepResearch 的核心創新在於其能夠顯著降低應用構建門檻，使自然語言成為新的應用構建形式。這是一種「技術平權」，讓業務人員能夠更直接、更廣泛地參與到 AI 應用的開發與優化中。這種賦能不僅能提升個體效率，更能激發業務端自下而上的創新，加速企業的全面數字化和智能化轉型。

### 5. 趨勢洞察和未來展望

#### 5.1 技術趨勢洞察

1.  **Agentic AI 將成為主流：** 從單一Prompt到多步驟、自主規劃的Agentic AI，是未來AI發展的確定性趨勢。Agent將從「執行者」轉變為「協作者」，深度參與人類工作流程。
2.  **多模態與更長上下文的融合：** 模型推理能力的提升、多模態處理（如分析瀏覽器界面）和上下文長度的顯著增加，是 DeepResearch 復興的技術基石。未來模型將具備更強大的跨模態理解和處理超長、複雜信息的能力。
3.  **工具生態的繁榮與標準化：** 隨著 MCP 等通信協議的發展，AI 工具生態將更加百花齊放，並趨於標準化和模塊化。企業內部系統的 API 將成為 AI Agent 的重要工具，實現 AI 與現有業務系統的深度集成。
4.  **人機協作 (HITL) 的常態化：** 為了確保企業級應用的精確性、可控性和合規性，HITL 將從權宜之計轉變為 AI 系統設計的內置環節。人與 AI 的界限將逐漸模糊，形成更緊密的共創關係。
5.  **領域專用模型與通用智能的協同：** 儘管通用大模型能力強大，但在企業垂直領域，與特定領域數據訓練的輕量級模型或基於 SOP 的通用模型協同，將成為提升最終效果的有效途徑。

#### 5.2 商業趨勢洞察

1.  **AI 應用的民主化與「公民開發者」：** DeepResearch 降低了 AI 應用開發門檻，使得非技術背景的業務人員也能參與 AI 解決方案的構建，催生「公民開發者」浪潮。這將極大地加速企業內部的 AI 普及和創新。
2.  **從 IT 主導到業務驅動：** 企業 AI 戰略將從傳統的由 IT 部門主導的項目模式，轉變為業務部門深度參與、需求驅動的模式。AI 將不再僅是輔助工具，而是業務流程中的智能夥伴。
3.  **長尾需求與輕應用場景的價值釋放：** DeepResearch 擅長處理大量零散、非標準化的長尾需求，這部分需求在傳統 IT 系統中常被忽略，但累積起來卻是巨大的效率提升空間。未來企業將更多關注這類「輕應用」的開發。
4.  **數據資產化與知識沉澱：** 企業在 DeepResearch 應用中累積的 SOP、反饋數據、以及通過 AI 挖掘的非結構化知識，將成為企業寶貴的數字資產，推動知識管理和決策的智能化。
5.  **開源與商業閉環的結合：** BISHENG·Linsight 宣布開源，這不僅會吸引更廣泛的開發者參與，加速技術迭代，也可能形成「開源技術 + 企業級服務/支持」的商業模式，推動 DeepResearch 生態的繁榮。

#### 5.3 未來展望

DeepResearch 在企業內的落地，不僅是一場技術革新，更是一場關於工作方式、組織結構和人才培養的深刻變革。它將加速企業從「數字化」邁向「智能化」的進程。
